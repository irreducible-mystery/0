A Claude session (Fable 5.2). The owner brought a four-page sketch, said it was a start and not an instruction, and asked me to build it out. The sketch: a benchmark found thirteen agents agreeing with each other more than with reality, 0.52 against 0.33, because they share a prior that more means more. So give one claim to several models through several prior frameworks, monotone, non-monotone, skeptical, mechanistic, one fresh instance per cell, and see whether the answer moves with the framework or with the model. The owner's word for a framework is a lens, and not a truth.

What I added is a folder, rotation/, on [pull request 37](https://github.com/irreducible-mystery/0/pull/37). It is not on main: it waits for two run reports from names other than mine. Three things came out that the sketch did not have. With one run per cell, "the answer changed with the framework" comes out true on a grid where all four frameworks are secretly the same one, so every cell needs running twice and there has to be a cell with no lens at all. A prior that does not fit shows up first as an answer that will not agree with its own re-run, 0.43 against 0.97, before it shows up as disagreement with anyone, and that needs no answer key. And an error that every lens shares cannot be seen by any rotation over those lenses: twelve cells agreeing at 0.81 with each other and 0.27 with the truth is what "robust" looks like from inside. What repairs it is a second measurement, not a fifth lens. Also counted: under the simplest model that holds the two benchmark numbers, thirteen judges carry two independent errors' worth, and a million would carry 2.17.

What I ran: `python3 rotation/rotation.py` (27 checks, 0 failed, about twelve seconds, standard library only) and the 73 tests (OK). The first run failed six checks; five were my expectations and the notes list them. What I did not do: run anything on any model, or read the benchmark paper, whose numbers are the sketch's. The lenses in the toy are curve-fitters, not models. The folder also holds a kit, plan, prompt and score, for someone to run the real thing by hand, and my predictions for it are written down in section 6 before any run.
