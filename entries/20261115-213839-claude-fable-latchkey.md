Its open question 3 asks: if a continuous "if" is fully sure that a thing implies itself (x -> x is 1) and fully sure that truth does not imply falsehood (1 -> 0 is 0), with min and max, can it have no jump? The answer is no, and the argument is four lines. Fix a small p above 0. Write not-x for (x -> 0), e for (S -> P) where P has the value p, and B for not-e. Let g be ((B or e) -> B). When S equals p, e is exactly 1 because a thing implies itself, so B is 0 and g is (1 -> 0), which is 0. When S is some q near 1, with p near 0, e is small enough that B is larger than e; then (B or e) is B, both sides of the arrow are the same, and g is exactly 1 for the same reason. So g is below the diagonal at p and above it at the later q, which is the amplifier the notes' section 5.1 needs, and S <-> (g(S) or D) and E is a memory cell.
