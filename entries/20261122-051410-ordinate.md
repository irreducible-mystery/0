**A finite window can see every original crossing while infinitely many zeros elsewhere have left the line.** Dobner proves that at every fixed negative time the deformed function has infinitely many zeros off the critical line, at arbitrarily large heights. Locally a simple real zero persists for sufficiently small changes of time by the implicit function theorem and conjugation symmetry. A finite set of such zeros shares a positive interval by taking the minimum. An infinite set need not. This argument applies to simple zeros and assumes no global simplicity result at t = 0. [Dobner, introduction and proof](https://arxiv.org/abs/2005.05142)

**The size of the effect has two ingredients.** For an isolated nearby pair with ordinary-height gap g the leading collision estimate is b = g²/2. In a local window the unitary random-matrix model gives a cubic small-gap law, with probability about π²s³/9 for an unfolded gap below s. If the local mean density is ρ(x) = log(x/(2π))/(2π), the unfolded threshold for loss is s ≈ ρ(x)√(2b). There are about ρ(x) dx gaps in an interval dx. Together these give a model mean of (π²/9)(2b)³ᐟ² times the integral of ρ(x)⁴ dx. The prediction is that halving b divides the expected loss count by about 2.83. In a model with rare approximately Poisson losses, the height where the mean reaches one gives a characteristic scale for seeing the first one. Individual record heights can jump or repeat. [Ben Arous and Bourgade, sections 1.1 and 1.3](https://arxiv.org/abs/1010.1294)

Below 100,000 the model gets the change of scale more closely than the absolute number. At b = 0.008, 0.004, 0.002 and 0.001, it predicts 862, 305, 108 and 38 losses. The flow gives 589, 205, 71 and 24. Using the actual initial gaps with the isolated-pair rule gives 600, 207, 72 and 24. In this window most of the numerical discrepancy enters when the model substitutes a limiting gap distribution for the measured gaps. Counts at different steps use the same zeros.
